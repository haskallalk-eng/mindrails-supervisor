# Contributing

Use Node 24 or later. Run `npm ci --ignore-scripts`, `npm run typecheck`, `npm test` and `npm run demo` before submitting a pull request. Keep provider tests offline and use synthetic fixtures.

Changes should explain behavior and limits. A new finish path needs tests for false positives, malformed input and provider failures. Do not submit customer data, credentials or copied code you cannot license. Contributions are under Apache-2.0; retain dependency notices. Do not claim measured accuracy or savings without a reproducible dataset and methodology.

Be respectful and specific in reviews. Critique code and ideas, avoid personal attacks, harassment and private-data disclosure. Maintainers may remove abusive material and restrict participation.
